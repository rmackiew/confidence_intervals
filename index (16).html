What to notice

Larger samples → smaller standard errors → narrower intervals. Higher confidence → larger critical values → wider intervals. In repeated sampling, the long-run fraction of intervals containing μ approaches the selected confidence level.

Important: The main diagram assumes the population SD is known, so it uses a z confidence interval: x̄ ± z × σ/√n. When σ is unknown, use the sample SD and a t critical value instead. Normal population sampling is used in the simulation to give exact coverage for the z method.
